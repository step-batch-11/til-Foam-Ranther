# Today I Learned

## Context : Building todo application

- Creation of Id should be handled in backend. Nobody should be able to send
  custom ids using other methods like curl.
- Creation of response should not happen in the task handlers(in-mem) : eg : you
  class shouldn't return response, it should return the id.
  - Then, you should create response out of it.
  - Suppose you want to use different db services , db can return anything, you
    shouldn't just send the data directly. According to the type of request made
    by client you should return the response.
- In place element manipulation is much easier.
- Rather deleting and appending the child element, We can directly use replace
  child.
- Template tag.
  - Anything inside the template tag won't be visible in html.
  - grab the template.
  - template.content.clon(true) will clone that element for you.
- **data-name** property which can be used to store data in html tags.
